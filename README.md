# Neuro-CDSS: Система анализа МРТ головного мозга

![Python](https://img.shields.io/badge/Python-3.11-blue?logo=python)
![PyTorch](https://img.shields.io/badge/ML-PyTorch-EE4C2C?logo=pytorch)

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1wyOU3QSd3mQXU_zsR_E2ptYPenkki3k7?usp=sharing)

**Neuro-CDSS** — система поддержки принятия врачебных решений для анализа 2D-срезов МРТ головного мозга (512×512) на базе нейросети **ConvNeXt-Base**. Программа определяет тип образования, выделяет поражённые области, позволяет вручную корректировать маску и формирует готовый протокол описания в формате Word (`.docx`).

---

## Основные возможности

* **Проверка входного изображения:** встроенный фильтр (Gatekeeper + расстояние Махаланобиса) отсекает посторонние картинки, не являющиеся снимками МРТ головного мозга.
* **Классификация на 4 класса:** глиома, менингиома, аденома гипофиза, норма (`no_tumor`) с выводом вероятностей по каждому классу.
* **Сегментация на 3 зоны и оценка неуверенности:**
  * **Ядро опухоли** (красный цвет).
  * **Воспаление и граница ГЭБ** (оранжевый цвет).
  * **Перифокальный отёк** (голубой цвет).
  * **Неуверенная зона** (жёлто-фиолетовый пунктир в местах с наименьшей уверенностью модели).
* **Быстрая загрузка снимка:** срез МРТ можно загрузить файлом с компьютера или вставить прямую ссылку / ссылку на файл Google Диска прямо в поле интерфейса (поддерживаются `.jpg`, `.png`, `.webp`, `.tif`, `.dcm`).
* **Измерения на срезе:** расчёт площади каждой зоны в квадратных миллиметрах (`кв. мм`), линейных размеров очага (`мм`) и автоматическое определение проекции среза (аксиальная, коронарная, сагиттальная).
* **Ручная коррекция:** маска модели открывается отдельным слоем поверх исходного МРТ. Врач может дорисовать зоны кистью или стереть лишнее ластиком, после чего площадь и текст протокола пересчитываются автоматически.
* **Экспорт протокола:** скачивание готового заключения на русском языке со встроенным снимком в Microsoft Word (`.docx`).
* **Пакетная проверка:** вкладка с демонстрационной плашкой на 20 снимков МРТ и вкладка массовой проверки папок или `.zip`-архивов с формированием карточек, графиков и таблицы результатов.

Для демонстрации проекта без установки программ и без входа в аккаунт Google сайт опубликован через туннель CloudPub:

## Способ 3. Локальный запуск через терминал (Windows, macOS, Linux)

Для локальной работы потребуется **Python 3.11** (подходят версии 3.10–3.12), **Git** и около 5 ГБ свободного места на диске.

### Шаг 1. Скачайте репозиторий

```bash
git clone https://github.com/marklemesev-spec/репозиторий СППР.git
cd репозиторий СППР
```

### Шаг 2. Создайте виртуальное окружение и установите библиотеки

**Windows (PowerShell):**

1. Установите [Python 3.11 (64-bit)](https://www.python.org/downloads/windows/), отметив при установке пункт **Add python.exe to PATH**, и [Git](https://git-scm.com/download/win).
2. Выполните в PowerShell:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если установлена видеокарта NVIDIA, для ускорения на GPU выполните перед `pip install -r requirements.txt`:

```powershell
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```

**macOS:**

1. Установите инструменты разработчика и Python 3.11:

```bash
xcode-select --install
brew install python@3.11 git
```

2. Создайте окружение и установите библиотеки:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

**Linux (Ubuntu / Debian):**

```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip git libgomp1
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

*(Если в Linux используется видеокарта NVIDIA, перед установкой `requirements.txt` выполните `pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124`.)*

### Шаг 3. Запустите программу

При первом запуске веса модели (~355 МБ) скачиваются автоматически в папку `cdss_workspace/checkpoints_512/`.

**Обычный локальный запуск (откроется на http://127.0.0.1:7860):**

```bash
python main.py --no-demo20
```

**Быстрый запуск с временной публичной ссылкой (для показа на другом ПК без туннелей):**

* Универсальная команда (Windows / macOS / Linux):
  ```bash
  python main.py --share --no-demo20
  ```
* Готовый скрипт для macOS (с защитой от перехода в спящий режим):
  ```bash
  chmod +x run_mac_share.sh
  ./run_mac_share.sh
  ```

После запуска в терминале и в верхней строке интерфейса появится временная ссылка `https://....gradio.live`. Её можно скопировать в один клик и открыть на любом устройстве. При остановке программы (`Ctrl + C`) ссылка сразу перестаёт работать.

**Дополнительные команды:**

* Полный запуск с автоматической сборкой плашки на 20 МРТ при старте:
  ```bash
  python main.py
  ```
* Анализ одного снимка (`.jpg`, `.png`, `.webp`, `.tif`, `.dcm`) прямо в терминале без браузера:
  ```bash
  python main.py --image path/to/slice.jpg --out ./results
  ```
* Запуск строго на процессоре CPU (если возникла ошибка видеокарты):
  ```bash
  python main.py --device cpu --no-demo20
  ```
* Самопроверка установки:
  ```bash
  python main.py --self-test
  ```

### Если веса модели не скачались автоматически

Если Google Диск временно ограничил скачивание, откройте ссылки из файла `config.py` в браузере, скачайте файлы вручную (`multitask_512_best.pth`, `mahalanobis_ood_512.npz`, `gatekeeper_512_best.pth`) и поместите их в папку `cdss_workspace/checkpoints_512/`.
